## 안녕하세요, 김지호입니다 👋

컴퓨터공학과 학생이고, **AI 에이전트와 함께 일하는 개발 방식**에 관심이 많아요.
아이디어를 빠르게 동작하는 서비스로 만들고, 실제 사용자가 쓰게 하는 것까지가 목표예요.

### 🤖 관심 분야

- **AI 에이전트 기반 개발 (Vibe Coding)**
  AI 코딩 에이전트에게 구현을 맡기고, 저는 **문제 정의, 설계 방향, 결과 검증**에 집중하는 개발 방식을 실험하고 있어요.
  "AI가 짜준 코드"가 아니라 **"AI와 함께 만들었지만 내가 이해하고 책임지는 코드"**를 지향해요.
- **사용자 중심 웹 서비스:** 만들고 끝내지 않고, 배포해서 실제 사용자 피드백을 받는 것까지
- **오픈소스:** 누구나 기여할 수 있는 구조를 설계하고 협업 흐름 익히기
